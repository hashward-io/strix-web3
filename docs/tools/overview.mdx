Strix Web3 agents use specialized tools to audit a blockchain protocol the way a real smart-contract auditor does: detect the ecosystem, build it, map it, fuzz it, and prove the bugs. The same tool set works across EVM, Solana, Move, Cairo, CosmWasm, TON, Substrate/ink!, ZK circuits, Sway, NEAR, Algorand, Cardano, and Bitcoin.

## Additional tools

| Tool | Purpose |
| ---- | ------- |
| Invariant catalog | Record the protocol's must-hold properties and their enforcement status |
| Threat model | The scan's shared attacker / trust-boundary document |
| Coverage ledger | One row per surface + risk area, including clean results |
| Notes | Durable cross-agent facts during the audit |
| Reporting | File findings with a proof and an inline fix |
| Web search | Look up a deployed contract, a protocol spec, or a known incident |
