---
title: "Sandbox Tools"
description: "Pre-installed multi-chain smart-contract audit tools in the Strix Web3 container"
---

Strix Web3 runs inside a Debian-based Docker container with a multi-ecosystem smart-contract audit toolchain pre-installed. Detect the target's ecosystem and use the matching tools through the [terminal](/tools/terminal).

## EVM

| Tool | Description |
| ---- | ----------- |
| [Foundry](https://github.com/foundry-rs/foundry) | `forge` / `cast` / `anvil` — build, test, fuzz, invariant, and fork tests |
| `solc` / `solc-select` | The Solidity compiler, pinned per project |
| [Slither](https://github.com/crytic/slither) | Solidity static analyzer (lead generator, not a verdict) |
| [Aderyn](https://github.com/Cyfrin/aderyn) | Rust-based Solidity static analyzer |
| [Echidna](https://github.com/crytic/echidna) | Property-based invariant fuzzer |
| [Medusa](https://github.com/crytic/medusa) | Coverage-guided stateful fuzzer |
| [Halmos](https://github.com/a16z/halmos) | Symbolic execution / bounded model checking |
| Vyper / Titanoboa | Vyper compiler and test framework |
| Node.js / npm / Hardhat | Projects that use the Hardhat toolchain |
| `cargo-stylus` | Arbitrum Stylus (Rust→WASM on the EVM) |

## Scripting & Decoding

| Tool | Description |
| ---- | ----------- |
| Python 3 | Venv with `web3`, `eth-abi`, `eth-utils`, `py-solc-x` |

<Note>
  All tools are pre-configured and in `PATH`. The agent detects the target's ecosystem and selects the appropriate toolchain for each audit stage — build, recon, fuzzing, or proof-of-concept.
</Note>
