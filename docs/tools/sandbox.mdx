---
title: "Sandbox Tools"
description: "Pre-installed smart-contract audit tools in the Strix Web3 container"
---

Strix Web3 runs inside a Debian-based Docker container with a complete Solidity / EVM audit toolchain pre-installed. The agent can use any of these tools through the [terminal](/tools/terminal).

## Build & Test

| Tool | Description |
| ---- | ----------- |
| [Foundry](https://github.com/foundry-rs/foundry) | `forge` / `cast` / `anvil` — build, test, fuzz, invariant, and fork tests |
| `solc` / `solc-select` | The Solidity compiler, pinned per project |
| Node.js / npm / Hardhat | Projects that use the Hardhat toolchain |

## Static Analysis

| Tool | Description |
| ---- | ----------- |
| [Slither](https://github.com/crytic/slither) | Solidity static analyzer (lead generator, not a verdict) |
| [Aderyn](https://github.com/Cyfrin/aderyn) | Rust-based Solidity static analyzer |

## Fuzzing & Formal Verification

| Tool | Description |
| ---- | ----------- |
| [Echidna](https://github.com/crytic/echidna) | Property-based invariant fuzzer |
| [Medusa](https://github.com/crytic/medusa) | Coverage-guided stateful fuzzer |
| [Halmos](https://github.com/a16z/halmos) | Symbolic execution / bounded model checking |

## Scripting & Decoding

| Tool | Description |
| ---- | ----------- |
| Python 3 | Venv with `web3`, `eth-abi`, `eth-utils`, `py-solc-x` |
| `cast` | State reads, calldata decoding, and on-chain simulation |
| Git | Repository history mining and diff scoping |

<Note>
  All tools are pre-configured and in `PATH`. The agent selects the appropriate tool for the audit stage — build, recon, fuzzing, or proof-of-concept.
</Note>
