## Prerequisites

- Docker (running) — the audit runs in a multi-chain sandbox container
- An LLM API key from any [supported provider](/llm-providers/overview) (OpenAI, Anthropic, Google, etc.)

## Installation

<Tabs>
  <Tab title="curl">
    ```bash
    curl -sSL https://strix.ai/install | bash
    ```
  </Tab>
  <Tab title="pipx">
    ```bash
    pipx install strix-agent
    ```
  </Tab>
</Tabs>

## Configuration

Set your LLM provider:

```bash
export STRIX_LLM="openrouter/z-ai/glm-5.3"
export LLM_API_KEY="your-api-key"
export ETH_RPC_URL="https://your-archive-rpc"   # optional, for fork-based PoCs
```

<Tip>
For best results, use `openrouter/z-ai/glm-5.3` (the default pick), `openai/gpt-5.4`, `anthropic/claude-opus-4-6`, or `openai/gpt-5.2`.
</Tip>

## Run Your First Audit

```bash
strix --target ./my-protocol
```

<Note>
First run pulls the Docker sandbox image automatically. Results are saved to `strix_runs/<run-name>`.
</Note>

## Target Types

Strix Web3 audits any supported chain/language. It accepts:

```bash
# Local project — the ecosystem is detected from the manifest
# (Foundry/Hardhat, Anchor.toml, Move.toml, Scarb.toml, Cargo.toml,
#  tact.config.json, Forc.toml, Nargo.toml, ...)
strix --target ./my-protocol

# GitHub repository
strix --target https://github.com/org/protocol

# Deployed on-chain target (verified source fetched by the agent; chain optional)
strix --target 1:0x0123456789abcdef0123456789abcdef01234567   # EVM
strix --target solana:9xQeWvG816bUx9EPfNqNKpS4Zk5N7gVvDLJq7YvYhq3f  # Solana
strix --target sui:0x2                                        # Sui package

# Multiple targets (e.g., a proxy and its implementation)
strix -t ./src -t 0x0123456789abcdef0123456789abcdef01234567

# Targets from a file, one target per non-empty, non-comment line
strix --target-list ./targets.txt
```
