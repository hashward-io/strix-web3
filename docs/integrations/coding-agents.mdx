Strix Web3 is built to be driven by AI coding agents. Install the official agent skills and your agent knows how to audit a blockchain protocol on any supported chain, remediate findings, and wire Strix into CI.

## Install the Skills

Works with any agent that supports the open [SKILL.md standard](https://agentskills.io) — Claude Code, Cursor, Codex, Gemini CLI, OpenCode, and dozens more:

```bash
npx skills add hashward-io/strix-web3
```

| Skill | What your agent learns |
|-------|------------------------|
| `auditing-smart-contracts-with-strix` | Audit a smart-contract protocol (local project, repo, or deployed address, any supported chain) and read the results |
| `find-solidity-vulnerabilities-with-strix` | White-box review of a Solidity/EVM codebase, with exploits to confirm findings |
| `fix-solidity-vulnerabilities-with-strix` | Triage findings, fix root causes, and re-run Strix to verify each fix |
| `ci-smart-contract-scanning-with-strix` | Add a diff-scoped contract audit gate to GitHub Actions or any CI |

Install a single skill with `npx skills add hashward-io/strix-web3 --skill auditing-smart-contracts-with-strix`, or use one without installing:

```bash
npx skills use hashward-io/strix-web3@auditing-smart-contracts-with-strix | claude
```

## How it runs

Strix Web3 is self-hosted and open-source: it runs locally in a Docker sandbox with your own LLM key. It is fully local and air-gap capable. Fork proofs need an archive RPC endpoint via `ETH_RPC_URL` (EVM); other ecosystems use their own local node/validator.

## Agent-Friendly Interfaces

Everything an agent needs is machine-readable:

- **Headless CLI** — `strix -n` runs without the TUI and exits with `0` (clean), `1` (error), or `2` (findings filed).
- **Structured results** — every run writes `audit_report.md`, `vulnerabilities/<id>.md`, `vulnerabilities.json`, `vulnerabilities.csv`, and `findings.sarif` (SARIF 2.1.0) under `strix_runs/<run-name>/`.
- **Budget controls** — `--max-budget` and `--max-turns` give agents hard cost/time caps; `run.json` records `status` and `llm_usage.cost`.
- **`AGENTS.md`** — the [repository's agent guide](https://github.com/hashward-io/strix-web3/blob/main/AGENTS.md) with a quick reference.
- **`llms.txt`** — this documentation is indexed at [docs.strix.ai/llms.txt](https://docs.strix.ai/llms.txt) and fully exported at [docs.strix.ai/llms-full.txt](https://docs.strix.ai/llms-full.txt); every page is also available as Markdown by appending `.md` to its URL.

Once the skills are installed, prompts like these just work:

```text
Audit this smart-contract repo with Strix (standard mode, $20 budget) and summarize the findings.
```

```text
Fix all critical and high findings from the last Strix run, then re-run to verify each fix.
```

```text
Add Strix contract auditing to our GitHub Actions so every PR that touches contract source files gets checked.
```
