---
title: "Scan Modes"
description: "Choose the right audit depth for your use case"
---

Strix Web3 offers three scan modes to balance speed and thoroughness. A separate `--scope-mode` narrows the run to a change set.

## Quick

```bash
strix --target ./my-protocol --scan-mode quick
```

The x-ray recon pass plus the core attack lenses over the main subsystems. Best for:
- CI/CD pipelines
- Pull-request validation
- Rapid smoke tests

**Duration**: Minutes

## Standard

```bash
strix --target ./my-protocol --scan-mode standard
```

The full lens set over the core subsystems plus the bug-class specialists the code shape warrants. Best for:
- Routine audits
- Pre-release validation
- Development milestones

**Duration**: 30 minutes to a few hours, depending on the protocol size.

## Deep

```bash
strix --target ./my-protocol --scan-mode deep
```

Exhaustive: every lens over every subsystem, protocol specialists, invariant fuzzing with Echidna/Medusa, and formal checks with Halmos. Best for:
- Comprehensive audits
- Pre-production / pre-mainnet reviews
- Critical protocol assessments

**Duration**: Hours, depending on target complexity.

<Note>
Deep mode is the default. It explores edge cases, chained vulnerabilities, and complex attack paths.
</Note>

## Change-Set Scope

`--scope-mode diff` narrows any depth to the changed `.sol` files, using the rest of the repository only as context. It is an overlay, not a fourth depth.

```bash
strix -n --target ./my-protocol --scan-mode standard --scope-mode diff --diff-base origin/main
```

## Choosing a Mode

| Scenario | Recommended Mode |
|----------|------------------|
| Every PR | Quick (+ `--scope-mode diff`) |
| Periodic audit | Standard |
| Before a major release or mainnet deploy | Deep |
| A high-value protocol, or contest prep | Deep |
