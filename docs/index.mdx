Strix Web3 is a team of autonomous AI agents that audit Solidity / EVM protocols like a senior auditor: they read the source, derive the protocol's invariants, run the specialist attack lenses, and prove every real finding with a Foundry proof-of-concept instead of a static-analysis alert.

## Use Cases

- **Pre-deployment audit** — Review a protocol before it ships
- **Second opinion / contest prep** — A systematic pass over the code with proof
- **Fork-based exploit validation** — Prove an oracle, price, or accounting bug on live state
- **CI gate** — A diff-scoped audit on every Solidity pull request

## Key Capabilities

- **Full EVM toolkit** — Foundry, Slither, Aderyn, Echidna, Medusa, Halmos, and a Python/`web3` runtime
- **Real validation** — Foundry proof-of-concept, not false positives
- **Multi-agent orchestration** — Twelve attack lenses and protocol specialists collaborate
- **Developer-first CLI** — Interactive TUI or headless mode for automation

## Audit Toolkit

Strix Web3 agents come equipped with a complete Solidity toolchain:

| Tool | Purpose |
|------|---------|
| Foundry | forge/cast/anvil for build, test, fuzz, invariant, and fork tests |
| Slither / Aderyn | Static analysis to seed leads (not a verdict) |
| Echidna / Medusa | Property-based and coverage-guided invariant fuzzing |
| Halmos | Symbolic execution / bounded model checking |
| Python Runtime | Custom exploit and decoding scripts (`web3`, `eth-abi`) |
| Invariant catalog | The protocol's must-hold properties and their enforcement status |

## Vulnerability Coverage

| Category | Examples |
|----------|----------|
| Reentrancy | Single/cross-function/cross-contract, read-only, callback |
| Access Control | Missing modifiers, broken initialization, privilege escalation |
| Price & Oracle | Spot/TWAP manipulation, staleness, decimals, single-source feeds |
| Precision | Rounding direction, truncation, decimal/scale mixing |
| Accounting | Conservation, solvency, share accounting, aggregate drift |
| DeFi-specific | Flash loans, ERC-4626 inflation, MEV, governance, token integration |
| Upgradeability | Proxy layout, delegatecall context, initializer front-running |

## Multi-Agent Architecture

Strix Web3 uses a graph of specialized agents for a thorough audit:

- **Distributed workflows** — Recon, per-lens specialists, and validation agents
- **Scalable coverage** — Parallel execution across the protocol's subsystems
- **Dynamic coordination** — Agents share the threat model, invariant catalog, and findings

## Quick Example

```bash
# Install
curl -sSL https://strix.ai/install | bash

# Configure
export STRIX_LLM="openrouter/z-ai/glm-5.3"
export LLM_API_KEY="your-api-key"
export ETH_RPC_URL="https://your-archive-rpc"   # optional, for fork PoCs

# Audit
strix --target ./my-protocol
```
